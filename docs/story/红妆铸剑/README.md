## 一致性锚点（跨文件共用）

- **昭昭**：朱红交领广袖长裙，外披半透明红纱，**腰间红缎带结在左侧**（分镜镜 01、镜 29 明确标注）；中分黑长发，白玉簪绾髻缠红绳；眉心一枚极小的银白星形额饰；左耳后发际一颗小痣；右手中指第二关节内侧一道浅色细疤。
- **无咎**：眼上黑布永不摘除（布宽三指、绕头两圈、脑后偏左死结）；右手虎口深色旧疤；斗篷左后下摆一块补丁。转世后**黑布不在位、双眼睁开、瞳色深褐**。
- **剑**：剑首剑格素面无饰，缠柄布人字形、收尾布结在柄身下三分之一；剑脊内侧一线极淡红光；剑脊旧缺口凡铁状态存在、神器状态起永久消失。锈迹在两种状态下都保留。
- **古籍与令符**：所有文字与刻痕全程**不可辨读**，不做清晰特写。

## 面部一致性做法（重要）

跨镜头五官漂移是本项目最大的技术风险，以下为已验证有效的做法：

1. **以面部特写作为参考图**，不要用全身图。全身设定图（如 1856×2080）里脸只占很小区域，作参考时提供不了足够的面部信息。
2. **提示词要短**（建议 300 字内）。长提示词会让服装、场景、光影的描述淹没面部权重，模型会淡化参考图的脸。
3. **景别要近**。大全景里人物只有几十像素高，脸没有足够像素去"像"任何人。
4. **不要用自己生成的图当下一轮的参考**，误差会逐轮累积放大；始终回到 `_assets/refs/face-a.jpg` 这张基准脸。

## 生成环境备注

- 生图有**单轮 10 张上限**。
- 提示词过长或参考图过多会导致 `MAX_TOKENS` 失败（模型推理阶段耗尽 token，响应里没有图像），此时应缩短提示词、减少参考图后重试。
